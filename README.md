Проект представляет собой интернет-магазин с админ-панелью, в котором можно просматривать, добавлять, редактировать и удалять товары.


📌 Используемые технологии:


🚀 Фронтенд

HTML, CSS, JavaScript — стандартные веб-технологии для отображения каталога товаров и админ-панели.

Bootstrap — для адаптивной сетки и стилизации интерфейса.

Fetch API — для взаимодействия с сервером через REST API.

🛠 Бэкенд

Node.js + Express.js — сервер для обработки API-запросов.

CORS — для разрешения кросс-доменных запросов между клиентом и сервером.

Body-parser — для обработки JSON-запросов.

Файловая система (fs) — для хранения товаров в products.json.

📡 API

REST API — реализованы стандартные CRUD-операции:

GET /admin/products — получить список товаров.

POST /admin/products — добавить товар.

PUT /admin/products/:id — редактировать товар.

DELETE /admin/products/:id — удалить товар.

📁 Хранение данных

JSON-файл (products.json) — база данных для хранения товаров.
