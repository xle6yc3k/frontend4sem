# 🛡️ JWT Auth App (Практика №13–14)

Простое приложение для демонстрации авторизации через JWT.

---

## ⚙️ Возможности

- Регистрация пользователя  
- Вход с сохранением JWT-токена  
- Доступ к защищённому API `/protected`  
- Swagger-документация по всем методам  
- Лёгкий HTML/JS frontend для взаимодействия с API

---

## 📦 Стек технологий

- **Backend:** Node.js + Express  
- **Frontend:** HTML + CSS + JS  
- **Библиотеки:** JWT, CORS, Swagger  
- **Документация:** Swagger UI (`/api-docs`)

---

## 🚀 Быстрый старт

### 🔧 Установка зависимостей

```bash
cd backend
npm install
```

---

### ▶️ Запуск сервера

```bash
node server.js
```

✅ Сервер будет доступен по адресу:  
`http://localhost:3000`

---

### 🌐 Открытие frontend

Открой `frontend/index.html` в браузере  
или запусти через Live Server (VS Code).

---

## 📘 Swagger-документация

API-документация доступна по адресу:

👉 `http://localhost:3000/api-docs`

---

## 🔐 Работа с токенами

- После входа вы получите JWT
- Он сохраняется в JS-переменной `token`
- При доступе к `/protected` он автоматически прикрепляется в заголовке:
  ```
  Authorization: Bearer <token>
  ```

---

## 🧪 Пример работы

1. Зарегистрируйтесь  
2. Авторизуйтесь (получите токен)  
3. Нажмите **"Получить защищённые данные"**

✅ Если токен валиден — данные будут выведены  
❌ Если нет — будет сообщение об ошибке
