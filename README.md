# 🚀 Практика 15–16: Кэширование, Cookie и Авторизация (Express.js)

Учебный проект по дисциплине **«Фронтенд и Бэкенд Разработка»** (МИРЭА, 2 семестр)  
Пример одностраничного веб-приложения с реализацией:

- ✅ Кэширования API-ответов на сервере
- ✅ Темной/светлой темы с сохранением через cookie
- ✅ Сессий и авторизации через `express-session`
- ✅ Мини-интерфейса входа/регистрации
- ✅ Простого хранения пользователей в JSON-файле

---

## 📂 Структура проекта

```
project/
├── server.js               # Сервер на Express
├── users.json              # Псевдо-база данных пользователей
├── cache/                  # Файлы кэша API
├── public/                 # Фронтенд
│   ├── index.html
│   ├── script.js
│   └── styles.css
```

---

## 🔧 Установка и запуск

> Требуется установленный [Node.js](https://nodejs.org/)

```bash
npm install
node server.js
```

Открой в браузере: [http://localhost:3000](http://localhost:3000)

---

## 🧠 Функциональность

### 💡 Темная/Светлая тема

- Переключается кнопкой
- Сохраняется в cookie (`document.cookie`)
- Стили меняются через `data-theme="light/dark"`

---

### ⚡ Кэширование API-ответов

- Запрос к `/api/data` возвращает кэшированную структуру
- Кэш сохраняется в `/cache/api_data.json` на 30 секунд
- Обновляется каждые 5 секунд (через `setInterval`)

---

### 🔐 Авторизация и Сессии

- Вход по логину/паролю сохраняется в `express-session`
- Идентификатор сессии передаётся через cookie (`connect.sid`)
- Проверка входа: `GET /check-auth`
- Выход: `POST /logout`

---

### 📝 Регистрация

- Простая регистрация через `POST /register`
- Данные сохраняются в `users.json` (в открытом виде — для практики)
- Защита от дублирования логинов

---

## 📸 Интерфейс

- Статичный HTML + JS
- Tailwind-like оформление
- Кнопки: смена темы, обновить данные, войти, зарегистрироваться, выйти

## 📌 Полезные команды

```bash

# Запуск сервера
node server.js

# Удалить весь кэш
rm -rf cache/*
```

## ⚠️ Замечания

- Пароли не хэшируются (учебная реализация)
- Не используется база данных — только JSON-файлы
- Только для запуска на `localhost` (без HTTPS)
