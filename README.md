# 📝 Заметки PWA

Прогрессивное веб-приложение для создания и хранения заметок — с поддержкой **офлайн-режима**, установки на **домашний экран** и минималистичным интерфейсом для быстрой работы на любом устройстве.

---

## 🚀 Возможности

- ✍️ Добавление, просмотр и удаление текстовых заметок  
- 💾 Хранение данных в `localStorage` (не теряются при перезагрузке)  
- 📱 Установка на телефон / планшет как настоящее приложение  
- 🌐 Работа **без интернета** благодаря Service Worker  
- 🔋 Адаптирован под мобильные устройства  

---

## 📦 Структура проекта

```
📁 pr17-18/
├── index.html           # Главная страница
├── app.js               # Логика добавления и удаления заметок
├── sw.js                # Service Worker (офлайн-режим)
├── manifest.json        # Web App Manifest
└── icons/               # Иконки для разных устройств
    ├── icon-16x16.png
    ├── icon-32x32.png
    ├── icon-192x192.png
    └── icon-512x512.png
```

## 🛠 Как запустить локально

1. Установи [Node.js](https://nodejs.org/)
2. Перейди в папку проекта:

```bash
cd pr17-18
```

3. Установи простой сервер и запусти с доступом извне:

```bash
npx serve --listen tcp://0.0.0.0:3000
```

> Альтернатива:
> `npx http-server -a 0.0.0.0 -p 3000`

4. Открой сайт:
   - на компьютере: [http://localhost:3000](http://localhost:3000)
   - на телефоне: `http://<ip_твоего_компа>:3000`  
     Пример: `http://10.192.220.100:3000`

---

## 📲 Установка как приложение (PWA)

1. Открой сайт в мобильном браузере (например, Chrome на Android)  
2. Появится кнопка: **«Установить приложение»**  
3. После установки оно будет доступно на домашнем экране  
4. Можно запускать в **полноэкранном режиме**, даже офлайн

## 🔧 Технологии

- HTML5 / CSS3 / JS (Vanilla)
- Service Worker API
- Web App Manifest
- localStorage
- PWA (Progressive Web App)

---

## 🧠 Полезно знать

- `manifest.json` должен находиться в корне проекта или `public/`
- Иконки в манифесте **должны существовать** и иметь `image/png`
- Для корректной работы Service Worker страница должна быть загружена **с localhost или HTTPS**
- Проверяй `Application` в Chrome DevTools:  
  - `Manifest` — для установки  
  - `Service Workers` — для кеширования и оффлайна
